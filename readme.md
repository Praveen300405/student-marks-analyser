# Student Marks Analyser

A simple Python project that calculates student marks, total marks, average marks, grade, and pass/fail status.

## Features

- Accepts student's name
- Accepts marks for five subjects
- Calculates total marks
- Calculates average marks
- Assigns a grade
- Determines pass/fail status
- Saves student results to a CSV file

## Grade System

| Average Marks | Grade |
|---------------|-------|
| 90 - 100      | A+    |
| 80 - 89       | A     |
| 70 - 79       | B+    |
| 60 - 69       | B     |
| 50 - 59       | C     |
| 40 - 49       | D     |
| Below 40      | F     |

## Pass / Fail

- Average marks >= 40 → PASS
- Average marks < 40 → FAIL
